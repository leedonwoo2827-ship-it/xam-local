# 과목게시판 스킨 — 복사해서 우리 것으로 쓴다

## 왜 복사하는가

서버에는 그누보드 기본 스킨 `basic` 하나뿐이다. 그런데 과목게시판은 **다른 게시판과
보여야 할 것이 다르다** — 글마다 `답변완료` 가 보여야 한다. 질문자가 목록만 보고
"내 질문에 답이 왔나" 를 알아야 하기 때문이다.

`basic` 을 직접 고치면 안 된다. 공지·문의 게시판이 같은 스킨을 쓰고, 그누보드를
올릴 때 덮어써진다. 그래서 **복사본을 만들어 과목게시판만 그것을 쓰게** 한다.

## 이름

```
basic-xam
```

★ **한글 이름을 쓰지 않는다.** 스킨 이름은 폴더명이자 경로로 쓰인다. FTP 문자셋이나
서버 파일시스템 인코딩에 따라 깨지면 게시판이 "스킨을 찾을 수 없다" 로 죽고,
그 상태에서는 관리자 화면으로 되돌리기도 번거롭다. 영문·숫자·하이픈만 쓴다.

## 어디에 두는가

| | 경로 |
|---|---|
| 로컬 (원본) | `260803-xam-lo\axexam\web\skin\board\basic-xam\` |
| 서버 | `/www/skin/board/basic-xam/` |

`axexam\web\` 이 `/www/` 를 그대로 미러한다. 그래서 `web/skin/board/` 에 두면
`stage.py`(발행 화면 ⑤ 업로드 폴더)가 **자동으로 담는다** — 두 파일 모두 `web/` 를
통째로 순회하므로 목록에 손으로 추가할 것이 없다.

## 만드는 순서

1. FileZilla 로 서버 `/www/skin/board/basic` 을 위 로컬 경로로 **내려받는다**
2. 내려온 폴더 이름을 `basic` → `basic-xam` 으로 바꾼다
3. `list.skin.php` 에 배지 두 줄을 넣는다 (아래)
4. 그누보드 관리자 → 게시판 관리 → `bigdata_sj` → **스킨** 을 `basic-xam` 으로
5. ★ **모바일 스킨도 따로 있다.** `bo_mobile_skin` 을 안 바꾸면 휴대폰에서는
   배지가 안 보인다. 모바일도 쓰려면 `/www/mobile/skin/board/basic` 을 같은 방식으로
   복사해 `basic-xam` 으로 두고 그 칸도 바꾼다.

## 배지 넣는 곳 — `list.skin.php` 두 군데

**① 목록 루프 앞에 한 번**

```php
include_once G5_PATH.'/exam/lib/qna_badge.php';
$ex_ans = ex_qna_answered($bo_table, $list);
```

**② 제목 옆 (루프 안)**

```php
echo ex_qna_badge($ex_ans, $list[$i]['wr_id']);
```

`답변완료`(초록) · `답변 준비 중`(주황)이 붙는다.

### 왜 판정을 스킨에 적지 않는가

답변 여부의 정본은 게시판이 아니라 **`ex_qna.qa_status = 'approved'`** 다.
게시판 댓글 수로 보면 회원끼리 주고받은 댓글까지 세어 `답변완료` 가 잘못 켜진다.
관리자가 확정한 답변만 완료다 — `exam/api/board.php` 도 같은 기준을 쓴다.

판정을 `exam/lib/qna_badge.php` 한 곳에 두면 스킨을 갈아타도 규칙이 따라온다.
스킨에 SQL 을 적으면 규칙을 고칠 때 스킨도 같이 고쳐야 한다는 것을 잊는다.

### 설계상 지킨 것

- **페이지당 쿼리 1회.** 목록 배열을 통째로 받아 `wr_id in (…)` 로 한 번에 조회한다.
  행마다 부르면 30건에 30쿼리다.
- **실패해도 죽지 않는다.** 배지는 부가 정보라, 못 읽으면 배지만 없으면 된다 —
  게시판 목록 자체가 흰 화면이 되는 것이 훨씬 나쁘다.
- **스타일은 인라인.** 스킨마다 CSS 클래스 체계가 달라서, 클래스만 뿌리면 어떤
  스킨에서는 모양 없이 글자만 붙는다. 배지는 눈에 보여야 뜻이 있다.

## 모양은 유지된다

지금 게시판이 세련되게 보이는 것은 스킨이 아니라 **`exam/assets/gnuboard-skin.css`
(19KB)가 basic 을 다시 칠하고 있는 것**이다. 그 CSS 는 `#bo_list` 같은 **그누보드
구조 선택자**를 쓰므로 스킨 폴더 이름과 무관하다 → 복사해도 모양이 그대로다.

★ 그래서 반대로, 복사본에서 **HTML 구조를 크게 바꾸면 모양이 깨진다.** `#bo_list`
같은 id·class 는 그대로 두고 안에 배지만 더한다.

## 다른 게시판도 스킨을 바꾸려면

같은 방식으로 복사본을 하나 더 만들거나, `basic-xam` 을 공유한다. 다만 과목게시판
전용 배지가 다른 게시판에서도 나오는데, `ex_qna_answered()` 가 그 `bo_table` 로
조회하므로 **일치하는 행이 없어 아무것도 안 붙는다** — 해롭지 않다.
