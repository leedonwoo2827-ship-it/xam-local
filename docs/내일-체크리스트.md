## 4. 문제가 생기면

| 사이트 전체가 백지 | `/adm/` 은 살아 있다 → 환경설정에서 테마를 `basic` 으로. 또는 FTP 로 `/theme/axexam` 폴더명을 바꾼다 |
| 특정 페이지만 백지·500 | 그 PHP 파일만 지우면 나머지는 돈다 |
| 헤더가 한 화면만 다름 | 세 곳 중 하나만 안 올라간 것 — `landing_template`·`check_template`·`theme/axexam/head.php` |
| 주소창에 도메인만 쳤는데 엉뚱한 데로 감 | 브라우저가 캐시한 옛 301. 시크릿 창으로 확인 |

**PHP 는 크기로 비교하지 않는다.** 응답만 나오지 소스가 안 나온다. 동작으로 확인한다.
**정적 파일도 크기가 다르게 보인다** — FileZilla 가 CRLF→LF 로 바꿔 올려서 줄 수만큼 작아진다. 정상이다.
