# 과목게시판 만들기 (문제집마다 1개)

빅분기용으로 새로 만들 때의 절차. **문제풀이·성적표·영상과 무관**하므로 급하지 않다 —
질문 게시판만 이게 없으면 비어 보인다.

---

## 규칙 두 개

**① 게시판은 문제집당 1개다.** 과목은 게시판이 아니라 **말머리**(`bo_category_list`)로
구분한다. 4과목이라고 게시판 4개를 만들지 않는다.

**② `bo_table` 이름이 규칙으로 정해진다.** `api/board.php` 의 `ex_board_table()` 과
`adm/exam_board_sync.php` 의 `exb_table()` 이 같은 식으로 만든다:

```php
$t = preg_replace('/[^a-z0-9_]/', '_', strtolower($pd_id));
return substr($t . '_sj', 0, 20);
```

| 문제집 `pd_id` | `bo_table` |
|---|---|
| `sqld` | `sqld_sj` |
| `bigdata` | **`bigdata_sj`** |
| `bdae-w` | `bdae_w_sj` (하이픈 → `_`) |

**이름이 틀리면 게시판을 못 찾아 조용히 빈 목록이 된다.** 에러가 안 난다.

---

## 절차

### 1. 그누보드 관리자에서 게시판 추가

```
/adm/  →  게시판 관리  →  게시판 추가
```

| 항목 | 값 |
|---|---|
| **테이블 이름** | `bigdata_sj` |
| 게시판 제목 | `빅데이터분석기사 필기 과목게시판` |
| 스킨 | 기본(basic) — 사이트가 `api/board.php` 로 읽으므로 스킨은 관리자 열람용이다 |
| 분류 사용 | **사용** (말머리 = 과목) |
| 분류 | 비워 둔다 — 다음 단계가 채운다 |

> `g5_board` 는 컬럼이 90개가 넘고 권한·스킨·업로드 정책이 다 거기 있다. 그래서
> **게시판 생성은 그누보드 기본 화면에서 한다** — 우리가 흉내내면 반드시 어딘가 빠진다
> (`exam_board_sync.php` 머리 주석).

게시판을 만들면 그누보드가 `data/file/bigdata_sj/` 폴더를 자동으로 만든다. 회원 첨부파일
자리이고 **우리가 뭘 올릴 곳이 아니다.**

### 2. 말머리 동기화

```
/adm/exam_board_sync.php   →  [동기화]
```

`ex_problem` 의 과목 목록(`sj_name` 4종)을 게시판 말머리로 맞춘다.

**이것만 자동화한 이유**: 과목명 오타 하나로 `api/board.php` 의 말머리 필터가 **에러 없이
빈 목록**을 돌려준다. 사람이 못 잡는 종류의 고장이다.

과목명은 `_rounds/mNN.json` 의 `subject` 에서 왔고, 요약노트의 `<h1>N과목 · 이름</h1>` 과도
**글자까지 같아야** 한다.

```
빅데이터 분석 기획 · 빅데이터 탐색 · 빅데이터 모델링 · 빅데이터 결과 해석
```

### 3. 확인

- `/adm/exam_board_sync.php` 가 게시판을 찾고 말머리 4개를 보여주면 끝
- 사이트에서 문제풀이 → 질문 탭에 과목 필터가 뜬다

---

## 회차가 늘거나 과목이 바뀌면

**2번만 다시 돌린다.** 게시판은 그대로다. 과목이 그대로면 아무것도 안 해도 된다.

---

## SQLD 21회분을 올릴 때

`sqld_sj` 게시판이 이미 있으면 그대로 쓴다. 과목이 2종(`데이터 모델링의 이해` ·
`SQL 기본 및 활용`)이므로 말머리도 2개다. 회차가 늘어도 게시판은 1개다.
